<p><strong>Wise Route Manager</strong></p>

<p>
Installs the Unraid webGUI launcher and setup helper for Wise Route Manager Lite.
The Route Manager application runs in its own Docker container, while this plugin
helps choose appdata storage, create the container, and open the web admin UI.
</p>

<p>
Provider credentials and route changes stay inside the Route Manager container.
Discovery is read-only until you explicitly approve a change plan.
</p>
